# Technology Stack

## Core Technologies
-   **Programming Languages:**
    -   **Rust:** Primary language for the core logic, backend server, and high-performance components.
    -   **JavaScript / TypeScript:** Used for the frontend of the desktop application and scripting integration.
    -   **Python:** Utilized for management scripts and tooling.

## Frameworks & Libraries
-   **Backend:**
    -   **Rocket:** Web framework for the Rust-based server components.
    -   **Tokio:** Asynchronous runtime for Rust, powering concurrent operations.
-   **Frontend / Desktop:**
    -   **Tauri:** Framework for building the cross-platform desktop application.
    -   **React:** UI library used within the Tauri application.

## Build & Management Tools
-   **Build System:** `Just` (Command runner) and `Cargo` (Rust package manager).
-   **Package Management:** `pnpm` (for Node.js dependencies) and `cargo`.
